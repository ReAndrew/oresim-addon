# OreSim for LiquidBounce

A [LiquidBounce](https://liquidbounce.net) add-on (Minecraft 26.3) that predicts where ores generated from the
world seed and outlines them through walls. Useful on servers where anti-xray hides the real ores.

It replays vanilla ore generation with the game's own classes (`WorldgenRandom`, the placed ore features and
their placement modifiers), so it follows the ore table of the Minecraft version you play.

> **The world seed is required.** The add-on cannot predict anything without it. In singleplayer it is read
> from the world automatically; on a server you have to know the seed and enter it yourself
> (`.seed <seed>`). With a wrong seed the shown ores will not match the real ones.

## Usage

- Enable **OreSim** (Render category). In singleplayer the seed is read from the world.
- On a server set the seed: `.seed <seed>` (or the module's **Seed** value). `.seed` shows the seed in use,
  `.seed clear` resets it.
- Settings: **ChunkRange**, **AirCheck** (hide positions next to air, i.e. already exposed or mined),
  one toggle per ore.
- **Baritone** (optional, needs the [Baritone](https://github.com/cabaletta/baritone) mod): with the setting on,
  `#mine diamond_ore` mines the simulated diamonds instead of searching. `.oresim mine [ores]`,
  `.oresim stop` and `.oresim status` drive it directly. With **PickUpDrops** (on by default) Baritone walks
  to the items a mined ore dropped before heading to the next one. **Overscan** (on by default) also
  sends it to real ores of the chosen kind that touch air, which the simulation itself hides.

## Accuracy

Measured against freshly generated worlds (predicted positions that are real ores / real ores that were predicted):

| Ore | Precision | Recall |
| --- | --- | --- |
| Iron, redstone, lapis, copper | 98–100% | 97–100% |
| Diamond, gold | 96–99% | 96–100% |
| Emerald | 94% | 97% |
| Coal | 47–69% | 44–71% |
| Nether gold, quartz, ancient debris | 98–100% | 100% |

The seed must be the world's real seed. Worlds generated by another Minecraft version are only right where
that version's ore generation matches 26.3.

## Building

`./gradlew build` produces `build/libs/oresim-<version>+26.3.jar`. Install it in LiquidLauncher under
Client settings > Mods > Add file, or subscribe to it in the LiquidBounce Marketplace.
